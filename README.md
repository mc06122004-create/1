# Stack Bot v1.0.0

Автоматический бот для браузерной игры Stack ("Башенки").

## Особенности версии 1.0.0:
- **Чистый геометрический анализ**: Обработка контуров не зависит от цвета блоков.
- **Предиктивный автокликер**: Динамический расчет мгновенной скорости и упреждения клика.
- **Интерактивный GUI**: Настройка области захвата и телеметрия в реальном времени.
- **Защита горячими клавишами**: `F6` (Старт/Пауза) и `Esc` (Аварийный стоп).

## Запуск из исходников:
1. `pip install -r requirements.txt`
2. `python stackbot/main.py` или запустите `Запустить Stack Bot.bat`

## Сборка EXE:
Запустите `Собрать EXE.bat`
